# 宏观驱动行业轮动方法手册

> 本文档是 agent-macro-driven-rotation Agent 的完整方法参考，供 Agent 在分析前阅读。
> 所有数据必须通过 Pandadata API（三个依赖 skill）获取，不得使用其他来源。

## 1. 改进版美林时钟详解

### 1.1 传统美林时钟局限

传统美林时钟以「产出缺口（GDP）」和「通胀（CPI）」两个维度将经济周期划分为四阶段。
在中国市场存在以下局限：
- GDP 数据发布滞后约 20 天，且平滑化处理后波动较小
- 中国信贷政策（社融/M2）对股市的影响往往先于 GDP 变化
- 政策干预频繁，阶段转换常被政策预期提前定价

### 1.2 四维改进框架

本 Agent 在传统双维基础上增加两个本土化维度。

**对话路径**：必须先 `get_macro_detail` 定码，不得凭记忆编造。  
**回测写死码**（与 `scripts/macro_catalog.py` 一致，定码日期 2026-07-30，仅供脚本复现）：

| 维度 | 核心指标 | 方法 | 示例代码 |
|------|---------|------|----------|
| **增长** | 制造业 PMI | `get_macro_ci` | `CI0000007` |
| **通胀** | CPI 同比 | `get_macro_pi` | `PI0000047` |
| **流动性** | M2 同比 / 社融存量同比 | `get_macro_mb` | `MB0000006` / `MB0000091` |
| **政策预期差** | PMI 新订单 − 产成品库存 | `get_macro_ci` | `CI0000009` − `CI0000012` |

易混旧码（勿再用）：`PI0000003`（居住:水电燃料，非 CPI 当月同比）、`MB0000002`（M0 同比，非 M2）、`FS0042573` + `get_macro_fs`（社融已改走 MB 类 `MB0000091`）。  
已废弃方法名（勿再使用）：`get_macro_pm`、`get_macro_fi`。

### 1.3 四阶段判定规则（与 `backtest.determine_phase_from_macro` 一致）

规则口径：
- 扩张：制造业 PMI > 50 且环比上行；否则收缩
- 高通胀：CPI 同比 > 2.0%；否则低通胀
- 宽松：M2 同比 > 8% 或 社融存量同比 > 10%

| 条件 | 主阶段 | 辅助字段 |
|------|--------|----------|
| 扩张 + 低通胀 + 宽松 | 复苏期 | `loose_liquidity=True` |
| 扩张 + 低通胀 + 未宽松 | 复苏期 | `phase_note=扩张低通胀但流动性未宽松` |
| 扩张 + 高通胀 | 过热期 | 流动性写入辅助列 |
| 收缩 + 高通胀 | 滞胀期 | — |
| 收缩 + 低通胀 | 衰退期 | 若已宽松 → `phase_note=衰退末期/政策托底` |

政策预期差 `policy_gap` 写入 CSV/报告辅助列；偏积极时可强化衰退末期注释，不单独改主阶段名。

## 2. 宏观阶段到行业映射完整表

### 2.1 复苏期受益行业

| 申万一级行业 | 景气逻辑 |
|-------------|---------|
| 电子 | 库存周期触底，消费电子需求复苏 |
| 计算机 | IT 投资需求随企业盈利改善回升 |
| 医药生物 | 消费属性加创新驱动，复苏初期防御转进攻 |
| 食品饮料 | 消费信心修复，可选消费扩散至必选 |
| 社会服务 | 出行餐饮需求弹性大，复苏弹性最高 |

（与 `AGENTS.md` / `scripts/industry_codes.PHASE_INDUSTRY_NAMES` 对齐；家用电器可作扩散观察，不列入初筛五行业。）

### 2.2 过热期受益行业

| 申万一级行业 | 景气逻辑 |
|-------------|---------|
| 有色金属 | 工业需求旺盛加全球流动性宽松 |
| 煤炭 | 电力需求高增，保供压力推高煤价 |
| 石油石化 | 全球需求旺盛，油价高位运行 |
| 钢铁 | 基建地产需求双驱，价格上传 |
| 银行 | 贷款需求旺盛，息差扩大 |
| 非银金融 | 交投活跃，股市上行 |

### 2.3 滞胀期受益行业

| 申万一级行业 | 景气逻辑 |
|-------------|---------|
| 农林牧渔 | 食品价格高位，猪周期溢价 |
| 医药生物 | 防御属性突出，刚性需求不随周期下行 |
| 公用事业 | 稳定分红，类债属性 |
| 交通运输 | 需求刚性，票价传导通胀 |

### 2.4 衰退期策略

衰退期不推荐股票行业，建议持有现金等价物、利率债、黄金。
若必须配置股票，可关注黄金股、公用事业、医药生物。

景气评分约定（主观约定，非官方指数，需标注）：
- 同比环比双升：+1（景气回升）
- 单项升、单项平：+0.5（景气偏暖）
- 趋势不明：0（中性）
- 单项降、单项平：-0.5（景气偏冷）
- 同比环比双降：-1（景气走弱）

### 3.3 index-valuation-rotation 调用参数映射

| 分析目的 | 调用方法 | 关键参数 |
|---------|---------|---------|
| 行业 PE/PB 分位 | get_index_indicator | 行业指数代码，5年窗口 |

## 4. 四象限图绘制规范

**所有图表通过 `scripts/chart_writer.py` 中的函数生成**，不得手动绘图或省略图表。

### 4.1 美林时钟钟面图（`render_clock_chart`）

- 圆形划分四扇区，顺时针：衰退、复苏、过热、滞胀
- 当前阶段扇区亮色填充，配色：复苏绿 `#2ECC71`、过热红 `#E74C3C`、滞胀橙 `#E67E22`、衰退蓝 `#3498DB`
- 扇区内标注推荐行业（最多 3 个），圆心标注"美林时钟 · 当前阶段"

### 4.2 增长-通胀散点轨迹图（`render_quadrant_chart`）

- 横轴：GDP 实际同比 / PMI 合成指数；纵轴：CPI 同比(%)
- 四象限：右上=过热、左上=滞胀、左下=衰退、右下=复苏
- 绘制近 24 个月经济轨迹线，颜色渐变（浅=过去，深=近期）
- 标注：当前（橙色大圆点）、6M前（灰色圆点）、1Y前（灰色方块）

### 4.3 估值-景气四象限图 L3 核心（`render_valuation_sentiment_chart`）

- 横轴：景气 Nowcast 分数（-1.0~+1.0），0 为分界
- 纵轴：行业估值温度 (0%~100%)，60% 为分界，数值越低越好
- 右下（高景气+低估值）= 推荐区（浅绿背景+★）
- 左上（低景气+高估值）= 规避区（浅红背景）
- 宏观阶段受益行业用橙色实心圆高亮，其余灰色空心圆

### 4.4 一次性调用三张图

```python
from chart_writer import render_all

charts = render_all(
    current_phase="复苏期",
    growth_series=pmi_series,        # pd.Series, index=datetime
    inflation_series=cpi_series,     # pd.Series, index=datetime
    industries_data=[
        {"name": "电子", "sentiment": 0.72, "valuation_pct": 38.0, "phase_match": True},
        {"name": "消费", "sentiment": 0.51, "valuation_pct": 42.0, "phase_match": True},
        # ...
    ],
    output_dir="./charts",
    data_date="2026-06",
)
# 用 charts["clock"][0]、charts["quadrant"][0]、charts["valuation"][0] 嵌入回复
```

## 6. 异常处理与降级策略

| 异常情形 | 降级动作 | 输出标注 |
|---------|---------|---------|
| macro-monitor 调用失败 | 跳过宏观定相，仅输出景气+估值 | 标注"宏观定相数据暂缺" |
| macro-altdata-nowcast 失败 | 跳过景气确认，仅输出宏观+估值 | 标注"另类景气数据暂不可用" |
| index-valuation-rotation 失败 | 跳过估值过滤，仅输出宏观+景气 | 标注"估值数据暂不可用" |
| 三个Skill全部失败 | 仅输出分析框架，不输出具体数值 | 完整标注所有缺失 |
| 图表渲染失败 | 降级为ASCII四象限表格 | 标注"图表生成失败，已降级" |
| 数据超过阈值（>60天） | 输出警告，提醒数据可能滞后 | 标注"数据时效风险" |

降级时不得凭记忆补充数据，只能如实说明缺失情况。
